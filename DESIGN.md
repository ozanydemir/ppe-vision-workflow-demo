# Interface design

This demo uses the shared **engineering routing desk** language for a human-reviewed computer-vision workflow. The central scene uses licensed stock photography as presentation context, paired with a synthetic detection ledger and review queue.

Bounding boxes, confidence values, and review states explain the pipeline without presenting a real detection result. They are synthetic and are never applied to the stock photo. Signal colors distinguish accepted detections from items requiring review. Responsive layouts keep the review context adjacent to each result.

The repository contains no private or workplace-derived imagery, identities, camera streams, trained weights, datasets, or accuracy claims. One licensed, credited stock photo is decorative presentation context only.
